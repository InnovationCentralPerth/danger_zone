Danger Zone

Agentic AI & Vision Language Physical Security

You are looking at an event-driven AI application that turns standard security cameras into proactive, thinking agents. Instead of just recording video, it uses Vision Language Models (VLMs) to analyze scenes, enforce safety rules, and log incidents autonomously.

👁️

Reading the Dashboard

The screen shows a real-time feed of events processed by autonomous agents.

  • Red Polygons: Exclusion zones. The system alerts if humans enter these areas.
  • Yellow Polygons: PPE required areas. The system checks if workers are wearing the required gear.
  • Agent Traces: Watch the log stream to see the AI "thinking" and reasoning about the images it captures.
💬

Dynamic "Mission" Context

The core innovation over legacy systems.

  • No code changes or model retraining required to change what the system detects.
  • We type safety rules in plain English (e.g., "Require safety glasses").
  • An LLM parses the request and updates the Vision Agent's instructions instantly.
🧠

Smart Analytics Watcher

AI processing is expensive. We don't send every frame to the cloud.

  • The system polls lightweight, on-camera Meraki analytics.
  • Only when a person is detected does the system trigger a snapshot.
  • Drastically reduces API costs and bandwidth while remaining responsive.
⚙️

Under the Hood

A decoupled, event-driven architecture.

  • FastAPI & Async: Handles multiple concurrent camera streams.
  • Event Bus: Webhooks trigger events, agents subscribe and react independently.
  • HTMX & SSE: Real-time frontend updates without heavy JS frameworks.
